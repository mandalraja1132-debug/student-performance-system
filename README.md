# Student Performance Analytics

A Python-based project to analyze student marks, grades, rankings, subject performance, and department statistics.

### Requirements

- Python
- Pandas
- Matplotlib
- Seaborn

### How to Run

1. Open `Untitled0.ipynb` in Google Colab.
2. Upload the four CSV files: `departments.csv`, `students.csv`, `subjects.csv`, and `marks.csv` to `/content/`.
3. Run all notebook cells sequentially using Runtime → Run all.
4. View the generated charts and analysis.
5. The final report is saved as `student_report.csv`.

Output: Student performance report, statistical summaries, and visualizations.
